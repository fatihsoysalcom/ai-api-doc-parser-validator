# AI API Doc Parser Validator

This example demonstrates the core concept of validating AI-generated API documentation using a parser. It simulates an 'actual API definition' and an 'AI-generated documentation string'. A simple parser extracts structured information from the AI-generated string, which is then compared against the actual API definition to identify inconsistencies.

## Language

`python`

## How to Run

Save the code as `main.py` and run it from your terminal:
`python main.py`
